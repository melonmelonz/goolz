Read a Stranger's Docs

Exercise 1 / 9 . core . Level 1 . 20 min

Goal: pick an API, find the four things in its docs, make one successful call. I picked Advice Slip -- random one-line life advice -- partly because it needs no key and no signup, and partly because a board built for people restarting their lives can absorb a line of borrowed wisdom without it being a gimmick. Open-Meteo was the responsible choice; this one fit the app.

The four things, found

ThingFound
base URLhttps://api.adviceslip.com
endpoints/advice random, /advice/{id} by id, /advice/search/{query}
authnone -- no key, no header, nothing
response{ "slip": { "id": 117, "advice": "It is easy to sit up and take notice..." } }

The whole doc is one short page, which turned out to be its own lesson: a small API documents like a small API, and the four things were all present anyway. Pasted the URL into the browser, got raw JSON, payload nested under slip -- not at the top level, which is exactly the kind of detail you only get by looking at a real response instead of assuming.

The undocumented fifth thing

Refreshed the browser tab to see a new slip and got the same advice. Refreshed again -- same advice. The docs mention, in one quiet line, that results are cached for two seconds; in practice browser-side caching stretched it much further until I added a junk cache-busting param (?t=Date.now()) like it is 2009. So the real four-things list has a shadow fifth entry: the behaviors the docs undersell. You find those by calling the API, not by reading about it. Logged for Exercise 2: my route sets cache: "no-store" on the outbound fetch, because Next loves to cache fetches too, and stale randomness is just a constant.

Checkpoint

Findings written down in the assigned format: API, base URL, endpoint, auth (none), response fields (slip.id, slip.advice). One successful raw call screenshot for the deliverable. Total docs-to-working-call time: about four minutes, of which three were the cache investigation -- a ratio I am told to expect from APIs for the rest of my life.
