Workflow documentation -- required template

WORKFLOW NAME:    First 90
TAGLINE:          Automated intake triage for the first 90 days that matter

FOR:              Small reentry / transitional-housing nonprofits
                  (2-4 case managers, 20-40 residents, no dedicated tech staff)

CLIENT PERSONA:   Program director who is accountable when a resident misses
                  a parole check-in. Not tech-averse -- uses Google Workspace --
                  but cannot maintain code. Pays to reduce catastrophic outcomes,
                  not to save time.

TRIGGER:          Webhooks by Zapier -- Catch Hook
                  (intake form on the nonprofit's site POSTs a JSON payload
                   with resident first name/initial and a free-text note)

ACTIONS (in order):
  1. AI by Zapier (gpt-5-mini)
     Extract structured JSON from the intake note:
     name, type, nextDate, urgency, isReal

  2. Filter
     Continue only if isReal = true AND type in
     {job, court, parole, cert, housing}
     Halts on spam, test submissions, or unrecognized appointment types

  3. Google Sheets -- Create Row
     Append to the case-management board:
     Name / Type / Next Date / Urgency / Logged At

  4. Paths (branch on urgency + type)
     Path A: urgency = urgent OR type = court
       -> Slack: immediate message to #on-call channel
     Path B: all others
       -> (logged; rolls into Monday digest -- see premium tier)

WHAT IT DOES:
  Receives a free-text intake note, extracts a structured record,
  filters out garbage, logs to the shared board, and immediately
  alerts the on-call case manager for any urgent or court-related entry.

TIME SAVED PER WEEK (estimate):
  Nightly review of pending appointments:  ~20 min x 5 nights = 100 min
  Hand-texting reminders to residents:     ~8 min x 20 reminders = 160 min
  Re-entering intake notes to spreadsheet: ~5 min x 15 notes = 75 min
  Chasing missed entries the next day:     ~30 min / 2x per week = 60 min
  ---
  Total saved: ~395 min / week, call it ~6.5 hours
  Conservative estimate I'd use with a client: ~6 hours / week

WHAT I'D CHARGE:
  Basic build (this Zap):    $900 one-time
  Optional maintenance:      $75 / month
  (covers Zapier plan share, prompt updates, new appointment types)

  Justification for the price:
  A missed parole check-in is not an inconvenience -- it can end a
  resident's housing and reactivate a sentence. The director does not
  need me to save her case managers 6 hours a week. She needs me to
  make that outcome less likely. $900 is cheap insurance on a grant
  that gets pulled if her program has a high recidivism rate.

Level 3 -- Premium tier

The basic build (documented above) is the foundation. The premium tier adds three capabilities:

AdditionWhat it doesHow it works
Monday digestcase managers start the week with a single email: who has what coming up in the next 7 days, sorted by urgencya scheduled Zap (every Monday 7am) reads the Sheets board, filters for nextDate within 7 days, and sends a formatted digest email to both case managers
Monthly summarydirector gets a once-a-month count: how many intakes by type, how many were urgent, how many upcoming dates logged -- program-level visibility without opening the spreadsheeta monthly scheduled Zap reads Sheets, counts rows by type and urgency for the prior month, sends a summary email to the director
Twilio SMS to residents48 hours before a logged appointment date, the resident receives a direct text reminder -- not mediated by the case managera daily scheduled Zap checks nextDate for entries within 48 hours, calls Twilio to send SMS to the resident's number (requires adding a phone field to intake)
Why the premium tier exists in the portfolio

The $900 build is the thing I can close in a single conversation. The $75/month and the premium tier expansions are the reason there is a second conversation. Clients who see the basic build working will ask "can it also text the residents directly?" The answer is yes, and it is scoped, and it has a number. Having it written down before the client asks is the difference between a freelancer and someone who looks like they have done this before.
